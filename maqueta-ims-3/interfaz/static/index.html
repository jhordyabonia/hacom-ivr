Prueba de verificación automática

Registra dos terminales IMS, verifica listeners y realiza una llamada del UE1 al Application Server (se espera que Asterisk reproduzca el IVR).

    Acciones rápidas

    —

    Buzón de voz (VMS)

    El Application Server (Asterisk) y una regla iFC encaminan al buzón 0100003: el UE llama, el AS saluda (IVR + prompts vm-*), graba el mensaje y lo guarda en .../voicemail/default/0100003/INBOX (msg*.WAV).

    —

    Enviar un mensaje desde la web

    Puedes grabar con el micrófono o seleccionar un archivo de audio (cualquier formato: wav, mp3, webm…). El sistema lo convierte a PCM16 8 kHz y lo graba en el buzón 0100003.

    —

    Suscriptores

    Datos que el UE usa para registrar y los que se envían a PyHSS al provisionar. Los cambios se guardan en el volumen ui_config.
